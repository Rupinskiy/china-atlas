# China GBA Atlas v2.2 - зміни й обмеження

Додано 7 точних дат пошуку бронювань (9 ночей), словник термінів із підказками, 5 варіантів Великого муру, LoungeKey risk protocol, 19 розмов англійською/китайською, 20 сервісів, Triple-Currency калькулятор, процедури доставки й покупки, оновлені транспортні підказки.

## Валютна обережність

Показані GBP/UAH Mastercard 61.2374, Visa 61.2419 з попереднього аналізу користувача на 24.10.2026. CNY/HKD/MOP → GBP взяті як ринкові орієнтири і не є фактичними Mastercard/Visa merchant-settlement rates. Змінюйте значення в калькуляторі після отримання фактичних списань.

## Реальні ризики

- Відвідування LoungeKey не гарантує нульового списання навіть за персонального Unlimited.
- Повернення HSR Badaling близько 09:22 не підтверджено на 4 листопада.
- Ціни їжі/доставки - оціночні, промокоди залежать від облікового запису та часу.
- APK встановлювати лише з перевірених сторінок розробника; пошукове посилання Google Play - не пряме завантаження APK.
- Готелі, документи та прикордонне рішення потребують фактичного підтвердження.

## PWA

Після Netlify deploy один раз завантажте Atlas для офлайн; актуальні shell JS включені в SW install і precache. Якщо зміни не видно, закрийте PWA і перевідкрийте/оновіть service worker.
