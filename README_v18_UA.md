# China Atlas v1.8 - Netlify PWA

Розгортання: витягніть усі файли цього ZIP у папку, перетягніть її в Netlify Deploy Manually так, щоб index.html лежав у корені. Після відкриття по HTTPS перезавантажте сторінку й натисніть «Завантажити весь Atlas офлайн». Потім перевірте режим польоту.

Новий розділ «Живий штурман v1.8»: день, місто, пошук, GPS (лише за натисканням), навігація Android, AMap (пошук китайською), OsmAnd, Google Maps. Маркери - орієнтовні центри POI, не обстежені входи. Пункт West Kowloon: B1 check-in/real-name verification, B3 Hong Kong + mainland immigration and boarding (згідно з офіційними правилами MTR, березень 2026). Для реального офлайн-роутингу завантажте локальні карти окремо в Organic Maps або OsmAnd і імпортуйте /data/poi-v18.gpx чи poi-v18.kml. Це маркери, НЕ прокладені піші шляхи.

Погодні альтернативи кожного з 11 днів працюють офлайн як текст. Онлайн кнопка збирає прогнози 16 днів через Open-Meteo для відповідних міст, кешує їх у localStorage і показує час отримання. Тайфуни/скасування перевіряйте за офіційними повідомленнями.

Книга China (2021): перевірено п’ять частин з Google Drive: manifest, текст і три частини медіа; історичні матеріали інтегровані тематично, чинні тарифи й візові умови не запозичуються зі старого видання. /data/epub-2021-audit.json - перелік перевірених ресурсів.

Увага: PRIVATE ZIP містить зображення з комерційного путівника та інформацію про маршрут. Netlify-сайт за замовчуванням публічний; пароль у самому HTML/JavaScript НЕ захистить ресурси. Завантажуйте PRIVATE тільки на реально приватний доступ; інакше використовуйте PUBLIC ZIP без книжкових ілюстрацій. Слід перевірити решту тексту і власні дані перед будь-якою публікацією.

Жодного автоматичного серверного відстеження GPS. Геолокація використовується в браузері для сортування найближчих точок за відстанню по прямій.

Обмеження тестування: серверне розгортання Netlify та встановлення на фізичний Pixel 8 Pro у цьому сеансі недоступні; перевірено вихідні ресурси, синтаксис, метадані, доступність внутрішніх шляхів.
