# China Travel Atlas v1.7 - розгортання Netlify та Pixel 8 Pro

## Розміщення на Netlify

1. Оберіть архів **PUBLIC** для загальнодоступного сайту. Архів **PRIVATE** містить фотографії зі сторонніх комерційних путівників і призначений лише для справді закритого приватного розміщення; перед публікацією перевірте налаштування доступу Netlify. Звичайна неоголошена URL-адреса або пароль, що перевіряється JavaScript, НЕ забезпечують захист.
2. Розпакуйте ZIP. У Netlify → Projects → Add new project / Deploy manually перетягніть **папку з вмістом**, де `index.html` лежить на верхньому рівні, або використайте відповідний механізм ZIP у вашій версії інтерфейсу.
3. Сторінку відкривайте через HTTPS-адресу Netlify. Перевірте, що `/manifest.webmanifest`, `/service-worker.js`, `/assets/netlify-v17.js` та `/data/city-anchors.gpx` відкриваються без помилок.
4. На Pixel 8 Pro: Chrome → відкрити сайт → оновити один раз → «Завантажити весь Atlas офлайн» → меню ⋮ → «Додати на головний екран» / «Встановити застосунок». Назва команди залежить від версії Android та Chrome.
5. До поїздки: у Chrome завантажте фото, відкрийте розділи, оновіть погоду/валюти для кешу; перейдіть у режим польоту й перевірте відкриття встановленого Atlas, фотокарток, гастрономії, GPX і нотаток.
6. Користуйтеся Organic Maps/OsmAnd окремо: завантажте регіони Пекін, Guangdong, Hong Kong і Macau, імпортуйте GPX або KML (це лише ПРИБЛИЗНІ центри міст, а не входи станцій).

## Які дані оновлюються онлайн

- Open-Meteo - погода для приблизних центрів міст (не для конкретної адреси), за запитом користувача; остання успішна відповідь зберігається локально з датою.
- ExchangeRate-API open endpoint - довідкові GBP→CNY/HKD/MOP, за запитом; за відсутності доступу показується останній локальний курс, якщо його вже було отримано.
- Офіційні транспортні посилання відкривають 12306, MTR, China Southern, AMap тощо у новому вікні. Ні наявність квитків, ні ситуацію на кордоні Atlas сам не перевіряє.

## Що працює без мережі

- HTML-енциклопедія, таблиці, калькулятори, чеклісти, локально завантажені зображення та навігаційні файли GPX/KML/GeoJSON.
- Доступ до останніх локально збережених результатів погоди/курсів (за умови, що дані раніше завантажено).
- Особисті нотатки й внесені витрати в localStorage **конкретного браузера і домену**.

## Що НЕ забезпечено

- Розгорнута карта вулиць усередині HTML офлайн; використовуйте Organic Maps/OsmAnd.
- Автоматичне отримання актуальних HSR-квитків і відстеження прикордонних черг.
- Автоматична синхронізація записів між ПК та Pixel; використовуйте кнопку експорту/імпорту JSON в Atlas v1.7.
- Гарантоване відкриття сторонніх API в материковому Китаї; останній кеш показується за наявності.
- Шифрування нотаток у localStorage. Не вносьте до них паспортні дані, повні квиткові номери, share codes чи платіжну інформацію.

## Безпека та ліцензування

- Публічний сайт Netlify потенційно доступний стороннім особам. Не публікуйте повні персональні маршрути, квиткові PDF, паспорти та контент із комерційних путівників.
- Пакет PUBLIC прибирає вбудовані 94 ілюстрації з книг та відомі власні імена, але інші відомості слід перевірити перед публікацією.
- Пакет PRIVATE містить 94 локальні медіафайли, що належать відповідним правовласникам. Використовуйте лише в закритому приватному середовищі.

## Оновлення та перевірка

Перед оновленням зробіть «Експорт JSON» на обох пристроях. Нова версія сайту повинна змінювати ключ кешу в `service-worker.js`; інакше при кешуванні старі ресурси можуть лишитися активними. Після оновлення Netlify відвідайте сайт онлайн і переконайтеся в оновленні PWA; за потреби закрийте та повторно відкрийте програму.
