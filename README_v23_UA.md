# China GBA Atlas v2.3 · наскрізні ціни і Wikipedia

## Наскрізні валюти

Після завантаження сторінки усі розпізнані суми (CNY, HKD, MOP, GBP, UAH, USD) відображаються з GBP та UAH; якщо первинна сума вже GBP чи UAH, додається локальна валюта відповідного розділу. Ставки можна змінювати у панелі 2.3. Обробляються також суми, вставлені JavaScript пізніше. Позначка ≈ означає, що це лише довідковий курс, а не гарантоване списання Mastercard / Visa. Навмисно не розпізнаємо числа без одиниці валюти, щоб не плутати час, номер рейсу, рік та обсяг даних.

## Вікіпедія

Статичні прямі посилання, перевірені веб-переглядом 24.10.2026, установлені для ключових міст, Великого китайського муру і династій Мін та Цін. Для інших прив'язаних назв застосовується верифікація за Wikidata: знайти конкретну EN-статтю за назвою, отримати її QID, потім перевірити sitelinks, вибрати ukwiki > ruwiki > enwiki; не створювати вигаданих адрес. Без мережі живе підтвердження може бути недоступним.

## Netlify

Корінь ZIP уже містить index.html, service-worker.js, всі дані й активи. Розпакуйте та завантажте папку на Netlify. Після оновлення сайту перезавантажте його, щоб установився новий service worker і v23 ресурс потрапив у кеш. Не використовуйте PRIVATE версію на публічно доступному домені без обмеження доступу.

## Межі охоплення

Це автоматична індексація чітко вказаних сутностей, а не повна лінгвістична розмітка всіх слів. Імена, не представлені в реєстрі, залишаються текстом. Для неперевірених сторінок офлайн-переходу не буде, щоб уникнути помилок. Українська пріоритетна навіть при російськомовних або англомовних вхідних назвах.
