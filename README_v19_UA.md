# China Atlas v1.9 - аудит джерел і геонавігації

Опублікуйте кореневу папку цього пакета на Netlify. Після оновлення сторінки використайте пункт «Завантажити офлайн» і перевірте локальну доступність розділів v1.9.

**Важливо:** дані входів мають provenance-status. Лише деякі мають WGS84 геоточку; не плутайте центр музею із дверима. GPX - waypoint, а не готовий пішохідний трек. На China mainland AMap використовує GCJ-02: краще відкривати китайські назви, ніж вставляти WGS84 без конвертації.

Перенесіть особисті дані через JSON export/import до заміни домену. Private build містить фото з комерційних книг - не завантажуйте на публічний Netlify без захисту доступу й дозволів правовласників.

Джерела v19: /data/verified-sources-v19.json. Чати: /data/chat-integration-v19.json. Незакриті проблеми: 240h TWOV Gongbei evidence, second Beijing night Qinghe vs PKX, безкоштовні CZ room availability, поїзди/готелі/страхування/лаунжі без персональних підтверджень.
