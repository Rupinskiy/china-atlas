# China Atlas v2.0 - Netlify PWA

Публікуйте `public` через Netlify Drop. Приватну версію з книжковими ілюстраціями не розміщуйте у відкритому доступі без контролю доступу.

Нові розділи: оперативний центр, 20 тематичних груп з позначенням особистих підтверджень, DiDi та калькулятор тарифу, Badaling Flight Go/No-Go, багаж PKX/Qinghe, Valhalla optional з fallback AMap/Organic Maps, культурні картки та оновлені джерела.

## Чесні обмеження
- Вбудовані в Badaling поля часу - зразки, не придбані рейси. Обов'язково шукати дату 2026-11-04 на 12306.
- Функціональне «закриття» інформації не підтверджує банківське право, фактично куплені квитки, виданий дозвіл NIA або страховку.
- Valhalla - demo-сервер, CORS/доступність у Китаї не гарантуються, результат залежить від OSM. Отриманий GPX після успішного Valhalla містить декодовану пішохідну лінію; без успішного маршруту GPX не створюється.
- Безкоштовний PKX склад слід перевірити безпосередньо: офіційна сторінка датована 31.07.2026.
- Personal statuses localStorage із експортом окремого JSON.

## Порядок перевірки
1. Netlify HTTPS: інсталяція PWA, двічі перезавантажити.
2. Airplane mode: відкриття всіх нових JSON/JS.
3. Відкрити v20 sections, зробити умовний розрахунок Badaling/таксі.
4. Повернути інтернет: запустити Valhalla; при недоступності обрати AMap/Organic Maps.
5. Зберегти прогрес у JSON, перевірити важливі бронювання в оригіналах.
